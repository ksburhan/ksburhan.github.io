# ksburhan.github.io

Burhan Köseler's project pages, served by GitHub Pages:

- `index.md`: the home page, a list of projects.
- `lockpick/index.md`: Lockpick's page, <https://ksburhan.github.io/lockpick/>.
- `lockpick/privacy.md`: Lockpick's privacy policy, <https://ksburhan.github.io/lockpick/privacy/>. Its source is
  `docs/privacy-policy.md` in the (private) game repo; copy changes from there.
- `lockpick/support.md`: Lockpick's support page, <https://ksburhan.github.io/lockpick/support/>.
- `app-ads.txt`: authorizes Google AdMob to sell the ads in the apps, <https://ksburhan.github.io/app-ads.txt>. It
  must stay at the site's root.

GitHub Pages builds the Markdown with Jekyll, using `_layouts/default.html`.
